# E-INVOICING FOUNDATIONS — UAE (player reference card)

## What is e-invoicing in the UAE?
Business-to-business (B2B) invoices must be issued, transmitted and stored **electronically in a standard machine-readable format** (PINT AE XML) — not PDFs, not emails, not paper. A new FTA framework governs it.

## The 6 things that make an invoice compliant
1. **PINT AE XML format** — the UAE standard structured format (not a scanned PDF, not an email)
2. **Both TRNs present** — the supplier's VAT registration number *and* the buyer's
3. **All 51 mandatory fields populated** — supplier/buyer details, dates, line items, tax codes, totals, payment terms, etc.
4. **Routed through an Accredited Service Provider (ASP)** — transmission must go via an approved provider
5. **Reported to the FTA in near real time** — not batched days later
6. **Unmodified and tamper-evident** — the file integrity must be provable

## Red flags — quarantine these
- ❌ Missing or malformed TRN (either side)
- ❌ Blank mandatory fields
- ❌ PDF / email / non-XML "invoice"
- ❌ No ASP routing or "direct email" transmission
- ❌ Credit notes without the original invoice reference
- ❌ Odd/rounded amounts inconsistent with the line items

## What happens if you get it wrong
UAE Cabinet Decision No. 106 of 2025 sets penalties for e-invoicing non-compliance — that is what this game simulates. A compliant filing process is not a back-office nicety; it is a regulatory obligation with financial teeth.

## Your decision loop
**SCAN → READ (check the 6 points) → FILE (looks compliant) or QUARANTINE (any red flag) → the platform shows the verdict + the rule → you learn.**
