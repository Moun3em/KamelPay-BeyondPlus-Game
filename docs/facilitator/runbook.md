# FACILITATOR RUNBOOK — Five-Corner Compliance Simulation

**One-page script. You run the room; the platform carries the mechanics.**

## Before the event (T-30 min)
1. Projection up: `…/projection` (big screen) + console open on your tablet/laptop: `…/console` → PIN `PREVIEW1234`
2. **Reset game** (console button, reason: "pre-event reset") → LOBBY
3. **Set Active tables** to the real headcount (3–10)
4. Verify every table row shows all devices once people join
5. Hand each table its envelope: table tent (PIN + join link) + card deck + this how-to-play card

## 09:00 — LOBBY (10 min)
- Welcome + the 5-min e-invoicing presentation (slide deck provided)
- "Open the link, enter your table PIN, claim your roles — CFO, Tax & Compliance, CIO, OPS, Procurement"
- Walk the room: every table must have ≥3 devices. Use **Red flags** on the console to spot stragglers
- Fewer than 5 per table? One phone can claim ALL roles

## TUTORIAL (3 min)
- One practice scan on every table (a known-good card). Check the WHY modal appears on phones
- **Console: advance to A** (reason: "practice done")

## Phase A — Internal Audit (12 min)
- The race is on. Walk the room; encourage volume, not perfection
- Watch **Red flags**: tables idle >3 min need a nudge
- **Do not** touch capital unless a real failure happened (phone died mid-scan → use Adjust)

## Phase B — Trading opens (8 min)
- Announce: "Procurement: find foreign invoices and bring them to the ASP"
- You are the ASP: **trade validation panel** — type Card ID, From, To, Validate. Both tables get +5,000
- Keep a short queue; validate as they arrive

## Phase C — Outages + green cards (10 min)
- Announce: "Outages are hitting. CIOs: fix your systems."
- **Console: advance to C** — outages arm automatically
- Resolve outages only if a table is genuinely stuck (Force-resolve)
- Watch the 150k cap — a table bleeding hard may need help

## FROZEN → DEBRIEF (5 min)
- **Console: advance to FROZEN** (reason: "end game") — leaderboard locks
- Show the projection: winner = highest compliant capital
- Debrief line: "You just did, under pressure, what a compliant e-invoicing pipeline does every day: read, decide, transmit, verify."

## Emergency playbook
| Problem | Action |
|---|---|
| A phone dies | Have them reopen — state restores. If not: new join, same PIN |
| Table stuck / outage won't clear | Force-resolve outage (console) |
| Wrong penalty applied | Adjust capital (console) |
| Camera fails everywhere | Manual "Enter card ID" path — game continues |
| Room chaos | PAUSE ALL, fix, Resume |
| Game must end NOW | Kill switch |
| Full restart | Reset game (only from FROZEN/LOBBY) |

**Golden rules for you:** every console action needs an audit reason (type it) · never hand out card verdicts — let the platform teach · the cards look identical — don't spoil it.
